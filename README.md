# Как писать художественную прозу на русском

Писательский скилл для моделей, которые помогают автору писать и редактировать прозу. На примерах из «Хроник Нотрона» и камерной истории о портнихе он показывает, как вести сцену от лица героя, строить диалоги, вводить читателя в устройство мира и вычитывать русский текст. Подходит и для работы с собственными персонажами и мирами.

**[Открыть SKILL.md](SKILL.md)** · [Прямой файл для передачи модели](https://raw.githubusercontent.com/StanislavSmetaninSSM/russian-fiction-writer/main/SKILL.md)

## Как пользоваться

**В обычном чате** приложите файл [SKILL.md](https://github.com/StanislavSmetaninSSM/russian-fiction-writer/raw/refs/heads/main/SKILL.md) вместе со своим отрывком и задачей. Можно начать с такой просьбы.

> Прочитай скилл и отредактируй разговор в этой сцене. Покажи, в какой момент дочь решается попросить отца остаться. Сохрани авторскую интонацию и открытый финал.

**В агенте с поддержкой скиллов** создайте в каталоге скиллов папку `russian-fiction-writer` и сохраните в ней этот файл под именем `SKILL.md`. В нём собраны методика, авторские правки до и после, отрывки для сравнения и порядок вычитки. Остальное устанавливать не требуется.

Основой послужили два писательских скилла «Хроник Нотрона», `notron-chronicle-writer` и `notron-prose-examples`. В [редакторской мастерской](SKILL.md#редакторская-мастерская-почему-автор-изменил-именно-эти-слова) можно увидеть, как автор менял смысл реплики, давал каждому участнику Совета собственное возражение и выстраивал сомнения Люциана перед необратимым выбором.
